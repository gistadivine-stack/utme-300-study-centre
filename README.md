# UTME 300 Study Centre

A static study website for CRS, Literature in English, Government and Use of English.

## Publish with GitHub Pages
1. Create or open the repository `gistadivine-stack/utme-300-study-centre`.
2. Upload `index.html` to the repository root (not inside another folder).
3. Commit the file to the `main` branch.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch **main**, folder **/(root)**, then Save.
7. Wait for GitHub Pages to finish publishing. The expected address is:
   https://gistadivine-stack.github.io/utme-300-study-centre/

## Progress saving
Completed sessions are saved in the visitor's browser using `localStorage`. This persists on that same browser/device after closing the site, but does not sync between devices. Private browsing or clearing site data may erase it.

## Important
The scheme of work is a starter study guide. Check the current official JAMB syllabus and the prescribed Literature texts for your examination year.
